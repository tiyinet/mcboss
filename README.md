萌宠老板 · 电脑端使用说明
版本 1.0  |  2026-10-08

========================================
一、这是什么
========================================
「萌宠老板」电脑端是一个桌面入口：打开它，就等于在电脑上打开你的店铺经营系统。
· 装完就像本地软件：双击桌面图标直接进入「店铺工作台」，没有地址栏、没有多余菜单。
· 自动更新：它加载的是线上系统，线上改了、加了功能，你这边重新打开就是最新的，不需要重新安装。
· 不用维护：日常业务变动（新功能、改文案）都自动跟随，不用管客户端。

========================================
二、安装
========================================
【方式一：安装版（推荐给店里固定的电脑）】
1. 双击 MengChongBoss-Setup-1.0.exe
2. 如果 Windows 弹出蓝色提示（"Windows 已保护你的电脑"），点 更多信息 → 仍要运行
   （这是软件未购买数字签名证书时的常规提示，不是病毒）
3. 选择安装位置：安装器会自动在你选定的路径下创建 MengChongBoss 文件夹，程序装在这个文件夹里。
   例：你选 D:\软件 → 实际安装到 D:\软件\MengChongBoss\
   直接点「下一步」用默认位置 → C:\Users\<你的用户名>\AppData\Local\Programs\MengChongBoss\
4. 装完后，桌面与开始菜单会出现「萌宠老板」图标，双击即可使用

【方式二：免安装版（U 盘拷走 / 多台电脑试用）】
解压 MengChongBoss-1.0-win.zip，双击里面的 MengChongBoss.exe 即可，不用安装。

========================================
三、使用
========================================
1. 双击桌面「萌宠老板」图标
2. 程序会直接进入「店铺工作台」；未登录时会先跳到登录页，用你的商家账号登录一次即可
3. 登录状态会被记住，下次打开不用再登
4. 之后就像用网页一样操作；窗口没有地址栏，就是个干净的软件界面

========================================
四、服务器地址（重要）
========================================
程序默认连的是正式域名 https://www.mcleyuan.com/ 。
域名备案还没生效、需要先用旧地址测试时，不用重新安装，只需：
1. 找到程序所在目录（安装版 = 你选的路径下的 MengChongBoss 文件夹；免安装版 = 解压出来的文件夹）
2. 在这个文件夹里新建一个文本文件，命名为 app.config.json
3. 重新打开程序，就会连到测试地址
正式域名生效后，把 app.config.json 删掉，程序就自动走 https://www.mcleyuan.com/ ，不需要重装。
提示：文件名必须是 app.config.json（不是 .txt），内容必须是合法 JSON，否则程序会忽略它、走默认域名。

========================================
五、常见问题
========================================
Q 首次打开弹蓝色警告？
A 点「更多信息 → 仍要运行」。属未签名软件的正常提示，本软件不捆绑任何第三方软件。

Q 打开后提示"暂时连不上服务器"？
A 检查电脑网络；页面会每 5 秒自动重试，也可以点「重新连接」。长期连不上请按第六节联系客服。

Q 打开后跳到登录页？
A 正常。店铺工作台需要商家账号，登录一次之后会记住。

Q 想换电脑用？
A 免安装版直接拷走；安装版在新电脑再装一次。

Q 忘记登录密码？
A 同网页端，在登录页走找回流程。

Q 想卸载？
A Windows「设置 → 应用」里找到「萌宠老板」卸载；卸载不会删除云端数据。
