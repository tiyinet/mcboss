一、萌宠老板是什么
════════════════════════════════════════════════════════

「萌宠老板」是一套宠物门店的数字化经营系统，由四部分组成，账号是同一个，数据是同一份。

1.1 四部分
────────────────────────────────────────────
  · 线上后台（主体）：浏览器打开 www.mcleyuan.com/admin，商家账号登录。门店的日常经营全在这里：收银、订单、预约、商品、库存、会员、营销、报表、连锁、设置，共 8 个分组、66 个功能模块。这是系统的主体，绝大部分工作都在这里完成。
  · 电脑客户端（本安装包）：装在店里的电脑上，双击图标直接进后台，不用开浏览器、不用记网址。额外多一项能力——断网也能收银开单。客户端是后台的一个入口加一层本地应急能力，不是另一套系统。
  · 手机端：小程序与手机网页，主要给顾客用（看店铺、预约、下单、查会员卡）。门店经营侧（收银、会员、库存、报表）目前只在电脑端，手机端暂不支持。
  · 商家官网：每个商家有一套自己的展示页，由后台「商家官网」三个模块装修，顾客从手机或电脑都能打开。


1.2 一句话理解它们的关系
────────────────────────────────────────────
  ▸ 后台是发动机，客户端是点火钥匙，手机端和官网是给顾客看的门面。钥匙坏了可以用浏览器直接点发动机；门面装修在后台里做。

1.3 这份说明的范围
────────────────────────────────────────────
以前的说明只写了客户端，漏掉了真正的主体。这一版把整个系统讲全：后台 66 个模块逐个说明（第六节），客户端单独一节（第七节），手机端与商家官网在相关模块里一并说明。

二、2.0 这一版升级了什么
════════════════════════════════════════════════════════


2.1 客户端换了架构
────────────────────────────────────────────
  · 从原来的内置浏览器方案换成本机系统内核方案，安装包从 178MB 降到约 2MB，内存占用明显下降，启动更快。
  · 界面重做：左侧导航按「本地经营 / 本地能力」分组，折叠按钮改成双向箭头，收起后只剩图标。
  · 新增断网收银：网络断了照样开单、打小票、开钱箱，来电后自动补传。


2.2 后台功能（与客户端无关，打开就是最新的）
────────────────────────────────────────────
后台在云端，我们更新之后你下次打开就是新的，不需要重新安装客户端。所以这一节不用记，知道「后台一直在更新」就行。

2.3 老用户升级必看
────────────────────────────────────────────
装新版之前，请先把旧版彻底退出，包括右下角托盘里的图标：
  · 方法一：右下角托盘图标上点右键 → 退出
  · 方法二：任务管理器里找到「萌宠老板」，结束任务

不退出就装，会出现新旧文件混在一起、打不开的情况。 装完之后数据不会丢，本机数据库还在原来的位置。

三、系统要求
════════════════════════════════════════════════════════


3.1 最低配置
────────────────────────────────────────────
  项目            要求
  ----------------------------------------------
  操作系统        Windows 10（64 位）或 Windows 11
  内存            4GB 以上（2GB 能开但会卡）
  硬盘            200MB 可用空间
  屏幕            1366×768 以上
  网络            首次登录与同步数据需要联网；之后断网可应急收银


3.2 Windows 7 / 8 / 8.1 不支持
────────────────────────────────────────────
如果你现在用的是 Windows 7 或 Windows 8，装不上或者装完打不开，这不是你电脑坏了，也不是安装包坏了。
原因：本软件靠系统自带的网页内核（WebView2）显示界面。这个内核对 Windows 7 的支持已经停止，微软不再为它发布新版本；程序自身也依赖了 Windows 8 之后才有的系统组件。所以无论在 Windows 7 上补什么运行库、装什么补丁，都启动不了。
这不是设置问题，改配置也解决不了。

3.3 Windows 7 用户的替代办法
────────────────────────────────────────────
用浏览器直接访问后台，功能基本一样。
  · 打开 Chrome 或 Edge，地址栏输入 https://www.mcleyuan.com/admin
  · 用同一个商家账号登录
  · 后台 66 个模块全都能用（收银、订单、会员、库存、报表、设置都在）
  · 唯一缺少的是断网收银能力——断网时网页打不开，这部分只能靠客户端

如果电脑上还是 IE 浏览器，请先装 Chrome 或 Edge（Windows 7 最高支持到 109 版本），IE 打不开现在的后台。

3.4 建议
────────────────────────────────────────────
Windows 7 已经停止安全更新很久，用它开单有数据风险。条件允许的话，把店里那台电脑升到 Windows 10 或 11，装客户端，用起来最省心。

四、安装
════════════════════════════════════════════════════════


4.1 安装步骤
────────────────────────────────────────────
  1) 先把压缩包解压出来，双击 MengChongBoss-Setup-2.0.15.exe 运行。
  2) 如果 Windows 弹出蓝色提示「Windows 已保护你的电脑」，点更多信息 → 仍要运行。这是软件未购买数字签名证书时的常规提示，不是病毒；本软件不捆绑任何第三方软件。
  3) 按向导点下一步。需要改位置就改，安装器会自动在你选的路径下创建 MengChongBoss 文件夹。

  ▸ 例：选 D:\软件 → 实际装到 D:\软件\MengChongBoss\ 直接点下一步用默认位置 → C:\Users\<用户名>\AppData\Local\Programs\MengChongBoss\
  4) 装完桌面和开始菜单会出现「萌宠老板」图标，双击即可使用。


4.2 为什么没有免安装版
────────────────────────────────────────────
2.0 用了系统内核，需要写入注册表、创建开始菜单项、注册开机自启，绿色版做不干净。所以只提供安装版。想在新电脑用，重新装一次即可，很快。

4.3 卸载
────────────────────────────────────────────
Windows 设置 → 应用 → 找到「萌宠老板」→ 卸载。
卸载不会删除你的经营数据。 数据分两处：
  · 云端：所有业务数据（订单、会员、商品、报表）都在服务器上，卸载重装后登录还在。
  · 本机：断网期间没来得及上传的订单，存在 C:\Users\<用户名>\AppData\Roaming\com.mcleyuan.mengchongboss\ 里。卸载前如果还有没上传的单，请先联网让它同步完。

五、第一次使用要做三件事
════════════════════════════════════════════════════════


5.1 第一步：登录
────────────────────────────────────────────
双击图标打开，第一次会停在登录页。用你的商家账号登录（手机号 + 密码）。登录状态会记住，以后打开直接进工作台。
没有账号，在官网 www.mcleyuan.com 点「免费注册」，或用微信联系客服开通。

5.2 第二步：同步门店数据
────────────────────────────────────────────
进后台后，点左侧「本地能力 → 同步中心」，点「立即同步」。
它会把线上的商品、会员、库存拉到本机，断网收银靠的就是这份本机数据。第一次必须做这一步，否则断网时收银台是空的。
同步完成后会显示：商品多少条、会员多少位、上次同步时间。

5.3 第三步：设置小票机（有小票机才需要）
────────────────────────────────────────────
点左侧「本地能力 → 打印与设备」，按第十节填端口和纸宽，点「测试打印」。能出小票就说明配好了。


════════════════════════════════════════════════════════
六、后台功能总览（系统主体）
════════════════════════════════════════════════════════

登录后左侧是导航，分 8 个分组。下面是全部 66 个模块的用途说明。
  ▸ 说明：后台在持续更新，模块会增删。以你登录后看到的菜单为准，本节讲的是每个模块负责什么。

6.1 店铺工作台
────────────────────────────────────────────
登录后的第一屏。看当天经营概况：今日营业、待处理订单、今日预约、库存预警、会员动态。相当于门店的仪表盘，每天上班先看一眼。

6.2 店面业务（8 个模块）
────────────────────────────────────────────
  · 收银台：门店现场开单。选商品或服务、选会员、收款、打小票、开钱箱。这是用得最多的模块。
  · 订单管理：查所有订单。按时间、客户、支付方式、状态筛选；可改单、退单、补打小票。
  · 预约服务：顾客预约的到店服务。看今天谁来、几点来、做什么项目，可确认、改约、取消。
  · 洗护报告：美容洗护的过程记录。给每只洗完的宠物留档（造型前后、用的产品、注意事项），可发给顾客看。
  · 寄养管理：寄养房间与入住记录。谁家的宠物在店、住哪间、喂什么、什么时候接走。
  · 转诊管理：需要转给合作医院或其他门店的病例记录，留住转诊去向和结果。
  · 提醒：到点要提醒客户的事。疫苗到期、驱虫、回访、取货，统一在这里排队发出。
  · 记账本：不走收银台的收支。房租、水电、进货、临时支出，记在这里，月底一起看。


6.3 商品服务（9 个模块）
────────────────────────────────────────────
  · 商品管理：卖的所有实物商品。名称、条码、进价、售价、规格、图片、上下架。
  · 服务管理：卖的所有服务项目。洗澡、美容、寄养、训练等，按分类管，设时长和价格。
  · 活体管理：店里在售的活体（猫狗鸟龟等）。品种、月龄、疫苗、来源、售价。
  · 云库商品：平台提供的公共商品库。可以直接挑来用，不用自己一条条录。
  · 商品库存：当前每个商品的库存数量，低于预警线会标红。
  · 入库管理：进货登记。录进货单、核对数量、成本入账。
  · 出库管理：非销售的出库。领用、报损、调出，都要走这里留痕。
  · 盘点管理：定期盘库。系统数和实物数对照，差异自动算出来。
  · 调拨管理：多门店之间的货品调拨。从哪家调出、调到哪家、多少件。


6.4 宠物商城（7 个模块）
────────────────────────────────────────────
  · 商城商品：放到线上商城卖的商品。和门店商品分开管，可单独定价、单独上下架。
  · 线上订单：顾客在商城下的单。看单、发货、填快递单号、批量导入发货。
  · 售后管理：退款、退货、换货的申请与处理。
  · 商城配置：商城的基础设置。运费、起送价、配送范围、营业时间。
  · 我的账户：商城的收款账户与结算记录。
  · 店铺装修：商城在手机上的样子。首页轮播、分类、推荐位。
  · 公众号：绑定公众号，做消息推送与粉丝沉淀。


6.5 客户中心（10 个模块）
────────────────────────────────────────────
  · 客户管理：所有客户档案。姓名、电话、生日、来源、消费记录，可导入导出、分组打标。
  · 宠物管理：客户的宠物档案。品种、生日、体重、疫苗、过敏史，跟着客户走。
  · 会员卡模板：储值卡的规则。面额、赠送、有效期、适用门店。
  · 次卡模板：次数卡的规则。洗护 10 次卡、寄养 7 天卡这类，按次核销。
  · 积分：积分规则与流水。消费送多少、能换什么、谁有多少分。
  · 会员营销：针对会员的定向动作。生日礼、沉睡唤醒、等级权益。
  · 课程首页 / 我的课程 / 课程订单：门店开的宠物训练课、养护课。发布课程、卖课、看谁报了名。
  · 留资线索：从官网、活动页留下电话的潜在客户。跟进、转化成正式客户。


6.6 营销推广（8 个模块）
────────────────────────────────────────────
  · 营销工具：发优惠券、拼团、满减、秒杀这类活动的配置台。
  · 营销管理：已建活动的统一管理。看效果、停掉没用的、复制再做一次。
  · 美团外卖 / 美团团购 / 淘宝闪购 / 京东秒送 / 抖音小时达 / 安心生活：六个外部平台的对接入口。在这些平台上卖的东西、接的单，统一在这里看，不用来回切后台。


6.7 数据统计（8 个模块）
────────────────────────────────────────────
  · 数据总览：一个页面看完关键数。营业额、客单价、新客数、复购率、热门项目。
  · 营业报表：按日、周、月看营收，含各项收入拆分。
  · 销售报表：卖得最好的是什么、哪个店员卖得多、哪个时段最忙。
  · 用户报表：客户结构。新客老客比例、消费分层、流失预警。
  · 店员报表：每个店员的业绩、提成、服务单量。
  · AI 周报：每周自动生成一份经营小结，指出问题和建议。
  · 多门店汇总报表：连锁商家用。各店横向对比，看谁在增长、谁在拖后腿。
  · 访问统计：官网和商城的访问量、来源、转化。


6.8 系统配置（13 个模块）
────────────────────────────────────────────
  · 门店信息：店铺名称、电话、地址、营业时间、简介、Logo。这一项改完，商家官网同步变。
  · 店员管理：加店员账号、设角色和权限。谁能看报表、谁能退款，在这里分。
  · 店员提成与排班：提成规则（按单、按额、按比例）和排班表。
  · 通用设置：系统级开关。单据编号规则、默认支付方式、语言等。
  · 打印设置：小票机的端口、纸宽、抬头、尾部文字、钱箱联动。
  · 消息推送：站内信、公众号消息、订阅消息的模板与开关。
  · 短信记录：发出去的短信明细，含成功失败状态。
  · 连锁资料库：连锁商家共用的资料（品牌、话术、标准流程），各店共享。
  · 操作日志：谁在什么时候改了什么。退款、改价、删数据这类敏感操作都有记录。
  · 回收站：误删的数据先放这里，可以还原。
  · 版本与订阅：当前版本、已开通模块、到期时间。
  · AI 智能助理：用说话的方式查数据、下指令。比如问「上个月洗护做了多少单」。
  · 激活码管理：用激活码开通模块或续期。


6.9 商家官网（3 个模块）
────────────────────────────────────────────
  · 官网展示：官网的整体呈现设置。开店/关店、显示哪些板块、联系方式。
  · 商家官网装修：页面装修。轮播图、模块顺序、颜色风格。
  · 模板选择：换整套官网外观。选好模板再微调，比从空白搭快。

七、电脑客户端（本安装包）
════════════════════════════════════════════════════════

客户端做两件事：给后台一个干净入口，以及在断网时保住收银。

7.1 界面结构
────────────────────────────────────────────
左侧导航分四块：
  · 工作台：进线上后台的店铺工作台，和浏览器打开是同一个系统。
  · 本地经营（离线可用）：收银台、订单记录、库存查询、会员查询。这四项断网也能用。
  · 本地能力：同步中心、打印与设备。
  · 设置：门店信息、云端账号、本地数据与备份、工作方式、启动与界面、关于与支持。

左侧的分组标题上标了「离线可用」，意思是这一组断网也能用；没标的（工作台）必须联网。

7.2 各栏目说明
────────────────────────────────────────────
  栏目          联网时                                 断网时
  ────────────────────────────────────────────────────────────────────────────────────
  工作台         正常进线上后台，全部 66 个模块可用                 打不开。此时请用「本地经营」这一组
  收银台         正常开单                                正常开单，数据先存本机
  订单记录        看本机最近 200 笔，可补传                     看本机订单
  库存查询        查本机缓存的库存                            查本机缓存的库存
  会员查询        查本机会员、余额、卡                          查本机会员、余额、卡
  同步中心        登录门店账号、拉数据、补传                       提示联网后再试
  打印与设备       配置小票机、测试打印                          配置仍可改，打印照常

  ▸ 本机数据是缓存，不完整。要查全量数据、要改商品改价格、要看报表，请用「工作台」进线上后台。本地这两项只服务断网应急。

7.3 折叠导航
────────────────────────────────────────────
导航栏底部有一个双箭头按钮：向左双箭头表示可以收起，向右双箭头表示可以展开。点一下切换，收起后只剩图标，屏幕小的时候更好用。状态会记住，下次打开还是你上次的样子。

7.4 开机自启与关闭行为
────────────────────────────────────────────
「设置 → 启动与界面」里可以打开开机自启。打开后每次开机自动运行并缩到右下角托盘，不占屏幕。
同一张卡里还有两项：
  · 关闭窗口时：可选「最小化到托盘」或「直接退出」。默认最小化，点右上角 × 不退出也不丢单。
  · 界面缩放：100% / 110% / 125% / 150%。屏幕大字小调大，屏幕小字挤调小，改完立即生效。

托盘图标右键有菜单：打开主界面、收银台、同步中心、打印设置、关于、退出。不管关闭行为选哪个，托盘菜单里的「退出」都能彻底退出。

7.5 按账号分开存
────────────────────────────────────────────
本机数据按登录账号各存一份，互不干扰：
  · 同一个账号换台电脑登录，看到的是自己店的数据。
  · 同一台电脑换账号登录，看到的是那个账号自己的数据，不会串。
  · 退出登录不删数据，重新登录原样恢复。

第一次装新版时，旧版留下的本机数据会自动并到当时登录的账号名下，一条不少；原来那份会改名成 mcboss.legacy.db 留在同一目录，不再参与运行。

7.6 备份与恢复
────────────────────────────────────────────
「设置 → 本地数据与备份」里能看到当前数据归哪个账号、占多大、存在哪个目录。
  · 立即备份：点一下就在本机留一份完整快照，备份列表里能看到时间和大小。
  · 恢复：在备份列表里点某一条的「恢复」。恢复前程序会自动把当前数据另存一份，万一恢复错了还能退回来。
  · 打开数据目录 / 打开备份目录：直接跳到文件夹，可以把备份拷到U盘带走，也可以换电脑时拷回来。

建议每次大改动前（比如批量改价、批量导入会员）先点一次「立即备份」。

7.7 自动补传
────────────────────────────────────────────
「设置 → 工作方式」里：
  · 自动补传：打开后，断网期间攒下的订单会在网络恢复后自动上传，不用手点。
  · 补传间隔：1 / 3 / 5 / 10 / 30 分钟。单量大的店可以调到 1 分钟。

八、收银台怎么用
════════════════════════════════════════════════════════


8.1 开一单
────────────────────────────────────────────
  1) 进「本地经营 → 收银台」。
  2) 找商品：扫码枪扫条码直接加；或者在上面搜索框输入名称/条码，点商品卡片加入。
  3) 改数量：在右侧单据里点商品行的加号减号；不要整行删掉，删掉要重新搜。
  4) 选会员（可选）：单据下方有会员选择框，输入手机号或姓名回车，选中后显示姓名和余额。不选就是散客。
  5) 选支付方式：现金、会员余额、扫码。
  6) 点「收款」。现金会算找零；会员余额会显示扣完剩多少。
  7) 自动打小票，钱箱自动弹开（如果在打印设置里开了联动）。


8.2 几种常见情况
────────────────────────────────────────────
  情况            怎么做
  ----------------------------------------------
  扫不出来        用搜索框输商品名，或输条码后回车
  价格不对        到后台「商品管理」改价格后点同步；临时改价在单据里直接改单价，改完记得跟客户说清
  收错了要退      后台「订单管理」找到这笔单，做退单；钱按原路退回
  会员余额不够    会提示余额不足，改用现金或扫码补差额
  现金单会不会扣会员余额不会。只有选「会员余额」支付才扣


8.3 小票打不出来
────────────────────────────────────────────
先看「打印与设备」里有没有配好、能不能测试打印。详细排查见第十节。


════════════════════════════════════════════════════════
九、断网怎么收银
════════════════════════════════════════════════════════


9.1 断网时能做什么
────────────────────────────────────────────
  · 开单收款（现金、会员余额）
  · 打小票、开钱箱
  · 查商品价格、查会员余额
  · 扫码枪照常可用
  · 扣减本机库存


9.2 断网时不能做什么
────────────────────────────────────────────
  · 扫码支付（需要联网）
  · 微信/支付宝收款
  · 改商品、改价格、看报表（这些在线上后台）
  · 新会员开卡、充值


9.3 断网时界面会怎么提示
────────────────────────────────────────────
点进「收银台」「订单记录」这类本地页面，顶部会显示一条状态提示：
  · 断网时：「已断网 · 正在使用本机数据，恢复网络后会自动同步」
  · 联网时：「这是本机缓存数据，最后同步 XXXX-XX-XX XX:XX · 完整数据请以线上为准」，后面带一个进线上后台的链接

看到第二种提示，说明你现在看的是本机缓存，要查全量请点那个链接。

9.4 来电之后
────────────────────────────────────────────
网络恢复后，客户端会自己把断网期间的订单补传上去，不需要你操作。
想手动确认：「本地经营 → 订单记录」，点右上角「补传待同步」。如果还有没传上去的，会提示数量并重新上传。
如果一直传不上去，多半是登录状态过期了：去「同步中心」重新登录一次门店账号，再回来补传。

9.5 会不会丢单
────────────────────────────────────────────
订单在收银那一刻就写进本机数据库，断网断电都不会丢。只是「上传到云端」这件事会推迟到有网的时候。
唯一的风险：本机数据库在 C 盘用户目录下，如果这台电脑重装系统或换电脑，没上传的单会跟着没。所以断网期间的单，来电后尽快让它同步完。

十、小票机怎么设
════════════════════════════════════════════════════════


10.1 先确认型号
────────────────────────────────────────────
支持三类：USB 小票机、网口小票机、并口（较老）。常见品牌：芯烨、佳博、映美、汉印。

10.2 填端口
────────────────────────────────────────────
进「本地能力 → 打印与设备」：
  · USB 接口：端口填 \\.\USB001

具体是 USB00 几，在「设备管理器 → 端口」里能看到。填错了打不出来。
  · 网口：端口填 192.168.1.xxx:9100（把 IP 换成你机器实际的）
  · 并口：端口填 LPT1


10.3 纸宽与抬头
────────────────────────────────────────────
  · 纸宽一般选 58mm 或 80mm，跟你机器里的纸一致
  · 抬头写店名，尾部可以写一句话（比如「感谢光临，下次见」）
  · 钱箱联动：勾上之后，现金收款时小票机自动给钱箱发开箱信号（钱箱必须插在小票机上）


10.4 测试
────────────────────────────────────────────
点「测试打印」。出纸了且字没歪、没缺行，就配好了。打不出来按下面查：
  现象            先查这个
  ----------------------------------------------
  完全没反应      打印机电源开了吗、USB 插紧了吗、驱动装了吗
  打出来是空白    纸装反了（热敏纸只有一面能显色）
  只打一半就停    纸宽选错了，58 的纸选了 80
  打出来乱码      端口填错了，去设备管理器核对
  有纸但指示灯红  缺纸或卡纸，开盖重装

十一、数据与同步
════════════════════════════════════════════════════════


11.1 以谁为准
────────────────────────────────────────────
以线上为准。 本机只是缓存。
线上改了商品价格、加了会员，本机不会自动马上变，要「同步中心 → 立即同步」拉一次。

11.2 多久同步一次
────────────────────────────────────────────
建议每天早上开店时点一次「立即同步」，这样本机的价格、库存、会员都是新的，白天断网也不慌。

11.3 数据在哪
────────────────────────────────────────────
  · 云端：订单、会员、商品、报表、设置，全在服务器上。换电脑登录就有。
  · 本机：C:\Users\<用户名>\AppData\Roaming\com.mcleyuan.mengchongboss\，里面是 mcboss.db。


11.4 换电脑怎么办
────────────────────────────────────────────
新电脑装一次客户端 → 登录 → 同步中心点立即同步 → 配好打印机。十分钟内能接着干。
旧电脑上如果还有没上传的单，先在旧电脑联网传完再换。

十二、常见问题
════════════════════════════════════════════════════════

问：装的时候弹出「Windows 已保护你的电脑」
答：点「更多信息 → 仍要运行」。这是未签名软件的常规提示，不是病毒，本软件不捆绑任何第三方软件。
问：双击图标没反应，或者提示缺少 MSVCP140.dll、VCRUNTIME140.dll 之类的文件
答：这是 Windows 缺少微软 VC++ 运行库（很多电脑装完系统没带）。到微软官网下载「Microsoft Visual C++ 2015-2022 Redistributable (x64)」装上，重启电脑再打开。
如果装完仍然提示缺少系统组件，请先确认系统是 Windows 10 或 11（见第三节）。
问：在 Windows 7 上装完打不开
答：本软件不支持 Windows 7，原因见 3.2。请用浏览器访问 https://www.mcleyuan.com/admin ，功能基本一样。
问：打开后一直转圈，左侧菜单点不动
答：多半是网络慢或者后台在更新。等十秒左右，遮罩会自动消失并提示可以先使用本地经营。如果一直不动，检查网络，或者在「设置」里退出重开。
问：打开后跳到登录页
答：正常。后台需要商家账号，登录一次之后会记住。
问：显示「这是本机缓存数据」
答：这是正常的提示，说明你在看本机缓存。要查全量点提示里的链接进线上后台。
问：断网两天，数据会不会乱
答：不会。订单先存本机排队，来电后按时间顺序上传，重复的自动跳过。
问：会员余额付款后余额没变
答：先确认支付方式选的是「会员余额」而不是「现金」。现金单不扣余额。
问：点商品加不进单据
答：2.0 已修好这个问题。如果还遇到，请把商品名和截图发客服。
问：忘记登录密码
答：在登录页走找回流程；找不回来联系客服重置。
问：能不能多台电脑同时用
答：可以，同一个账号在多台电脑登录都能用。但断网收银的本地数据各存各的，不要两台电脑同时给同一个客户开卡。
问：换店 / 换门店 ID 部署
答：客户端在设置里可以填门店编号，不用改程序。具体联系客服。
